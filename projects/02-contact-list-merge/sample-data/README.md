# How the data looks in Excel

Project 02 merges six lead exports plus a template. **The real course dataset is not included in this repository.** This folder holds a small **synthetic** sample (37 rows, all invented) generated by [`../scripts/make_sample_data.py`](../scripts/make_sample_data.py). It has the same sheet names and column headers as the exports the pipeline was built against, and it reproduces the same *kinds* of mess, so the tests, the JS/Python parity check and the end-to-end run all work on a fresh clone.

To run the pipeline on your own exports, keep the same file names, sheet names and headers (below) and point `GTM_DATA_DIR` at the folder.

```bash
python3 scripts/make_sample_data.py        # regenerate this folder
GTM_DATA_DIR=/path/to/your/exports python3 -m pipeline.run
```

Real vendor exports have many more columns (Apollo about 50, ZoomInfo about 90). The pipeline reads only the columns listed below; everything else is ignored.

|---|---|

| Nickname vs formal name | `Kate` / `Katherine Doyle` |
| Several scraper snapshots linked by Sales Navigator id, no public slug | `Hana Weiss` |
| Typo e-mail repaired because the company domain is known | `Tom Baker` (`.con`) |
| Phone columns of different trust; damaged, landline and fake numbers; an uncorroborated "Work Direct" number | `Ravi Menon`, `Nina Cho`, `Sam Ortiz` |
| Personal e-mail only | `Zed Quill` |
| Removed rows: test lead, student, `asdf` spam, two hidden `LinkedIn Member` profiles | 5 rows |

Expected result: 37 rows in, 5 removed, **12 people** out (`../expected-output/`).
