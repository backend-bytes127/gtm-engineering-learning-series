# Sample data

`contacts.csv` is a **synthetic** contact list of 36 rows, generated by `scripts/make_sample_data.py`. Every person and company is invented and every domain ends in `.example`. It mimics the output of [project 02](../../02-contact-list-merge/README.md) (a "clean" list), with defects added on purpose so each validation rule has something to catch.

Columns: `Full Name, Company, Job Title, Work Email, LinkedIn Profile, Sequence, Status`. The importer maps these automatically; project 02's own `Final_Contact_List.xlsx` headers (`Contact Person Name`, `Company Name`, `Designation/Job Title`, `Email ID`, `LinkedIn URL`) map too.

| What | Rows | Expected result |
|---|---|---|
| Normal contacts | 17 | kept |
| LinkedIn only (no e-mail) | 2 | kept; e-mail steps are skipped for them |
| E-mail only (no LinkedIn) | 2 | kept; LinkedIn steps are skipped for them |
| E-mail with a typo domain (`gmial.com`) but a valid LinkedIn | 1 | e-mail cleared, kept on LinkedIn |
| Company-page URL in the LinkedIn column, valid e-mail | 1 | LinkedIn cleared, kept on e-mail |
| Role account (`info@`) | 1 | kept, flagged `email_risky` |
| Malformed e-mail, no LinkedIn | 1 | removed: `invalid_email` |
| Disposable e-mail, no LinkedIn | 1 | removed: `invalid_email` |
| Same e-mail as another row (different case) | 1 | removed: `duplicate` |
| Same LinkedIn as another row (`http://`, different e-mail) | 1 | removed: `duplicate` |
| Status column says `Unsubscribed` | 1 | removed: `opted_out` |
| E-mail, `@domain` and LinkedIn URL on the suppression list | 3 | removed: `opted_out` |
| No e-mail and no LinkedIn | 1 | removed: `no_reachable_channel` |
| No name | 1 | removed: `missing_name` |
| One kept contact with **no company** | 1 | blocks the launch gate until held back (see the main README) |
| One kept contact with no job title | 1 | fine: the template has a fallback for it |

Result: **36 read, 26 kept, 10 removed.** The numbers are asserted in `sequencer/tests/test_simulate_workflow.py`.
