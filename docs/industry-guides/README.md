# Industry GTM guides

Four working guides to selling business software, focused on the Netherlands and Germany. They are written for learners and job candidates.

| Guide | Covers |
|---|---|
| [B2B SaaS and product-led growth](b2b-saas-gtm.md) | Motions, buying gates, signals, outreach rules, editable market-size model |
| [Cybersecurity software](cybersecurity-gtm.md) | Segments, buying committee, regulation, signal-to-play flow |
| [B2B fintech software](fintech-gtm.md) | Segments, regulation dates, buying journey, signal-to-play flow |
| [Logistics and warehouse technology](logistics-tech-gtm.md) | Routes to market, buying cycle, regulation dates |

**Read before using them**

- Facts were checked as of late November 2026, and rules and dates change. An independent review spot-checked sources; it did not open every one.
- **Nothing here is legal advice.** Have the outreach-law sections confirmed by counsel in each country.
- Market-size figures are **worked examples with invented assumptions** (fit, price, share). Only the company counts are sourced. Change the inputs and rerun the code block.
- Some analyst figures come from press coverage rather than the original report, as each guide notes.
- Sample messages in Dutch or German need a native speaker's review. Segments, scoring weights and 30-60-90 plans are untested proposals.
