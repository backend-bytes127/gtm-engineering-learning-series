# Diagrams

Architecture diagrams are drawn in [Excalidraw](https://excalidraw.com). Each `.excalidraw` file is the editable source; the `.png` next to it is the export used in the docs.

| Diagram | Used in |
|---|---|
| `platform-overview` | root README, `docs/architecture.md` |
| `contact-merge-flow` | Project 02 README, `docs/architecture.md` |
| `build-and-test-pipeline` | `docs/architecture.md` |
| `outreach-sequencer-overview` | Project 03 README |
| `outreach-send-decision` | Project 03 README |
| `outreach-ai-guardrails` | Project 03 README, ADR-0010 |

To change one: open the `.excalidraw` file in excalidraw.com (File > Open), edit, save it back over the file, and export a PNG at 2x scale next to it. Process maps of the two workflows are separate and live in [`docs/workflows/`](../workflows/README.md).
